# EveryWatch Secondary Market Pulse

A full-screen, filter-linked market-intelligence dashboard built from 300 synthetic luxury-watch secondary-market records.

[View the live dashboard](https://ioannisbekas.github.io/everywatch-market-dashboard/)

## Dashboard

- Four global slicers for region, brand, channel, and listing status
- A filter-linked 3D market map covering 21 cities
- Sold GMV, listings, sell-through, and time-to-sell indicators
- Monthly GMV, channel liquidity, and brand-concentration views
- An EveryWatch brand-data film generated with Higgsfield AI

## Local development

```bash
npm install
npm run dev
```

Create the GitHub Pages-ready static export with:

```bash
npm run build
```

The export is written to `out/`.

## Data and brand notice

This is a visualization demo using synthetic sample data. It is not investment advice or a live market quotation. The EveryWatch wordmark in the interface is the supplied official brand asset; it has not been recreated or altered.
